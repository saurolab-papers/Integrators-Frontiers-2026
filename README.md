# Integrators-Frontiers-2026
This repository contains simulation files for our Integrators paper. The paper is titled "Biochemical integral feedback control requires neutral stability and zeroth order reactions" and is by Steven S. Andrews, H. Steven Wiley, and Herbert M. Sauro. We submitted it to Frontiers in Systems Biology in July of 2026 and, as of September 2026, it is still under review.
